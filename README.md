# Family Utility App

A private, offline-first utility app for one family: PDF, convert, compress, scan, images, a shared live family layer, and personal records. No accounts, no ads, no cloud AI, no third-party servers.

Start with [MASTER_PLAN.md](MASTER_PLAN.md). Every feature has a spec in [features/](features/). Progress is tracked in [PROGRESS.md](PROGRESS.md).
